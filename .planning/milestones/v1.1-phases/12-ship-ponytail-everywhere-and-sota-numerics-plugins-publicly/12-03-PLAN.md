## Alternatives Considered

- **`github` source object (`{"source": "github", "repo": "owner/repo"}`)**: the documented type for
  a marketplace entry pointing at a plugin hosted in a different GitHub repository; resolves the
  default branch's commit SHA as the version when left unpinned.
  `https://code.claude.com/docs/en/plugin-marketplaces` (2026, fetched and quoted verbatim in
  12-RESEARCH.md this session).
- **`url` source object (generic git URL)**: the same cross-repo capability expressed as a full clone
  URL rather than an `owner/repo` shorthand — necessary for non-GitHub hosts, redundant here, and
  strictly longer to write. Same doc, `https://code.claude.com/docs/en/plugin-marketplaces` (2026).
- **`git-subdir` source object**: points at a repository plus a `path` within it, which would let the
  two plugins keep living as subdirectories of `gsd-beads` with no separate repos at all. Same doc,
  `https://code.claude.com/docs/en/plugin-marketplaces` (2026).

Decided by: simplicity/LOC. All three resolve over the same git fetch, so the ranked performance
criterion ties; `github` expresses the intent in two fields where `url` needs a full clone URL, and
`git-subdir` is eliminated outright by locked decision D-01, which requires each plugin to have its
own repository rather than remain a subdirectory.
