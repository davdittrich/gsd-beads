## Alternatives Considered

- **Direct hook invocation plus scratch-dir predicate evaluation**: run the installed plugin's own
  `hooks/session-start.sh` with `CLAUDE_PLUGIN_ROOT` pointed at the resolved cache root, then evaluate
  the gate with `gsd_run check predicate` against a scratch phase directory. This is the exact
  invocation `hooks/hooks.json` registers, so it reproduces a real session start rather than
  approximating one, and it is the technique both prior phases used for the gate half:
  `.planning/phases/13-markdown-linting-capability-dogfood/13-GATE-SMOKE-TEST.md` (2026) and
  `.planning/phases/14-pr-workflow-capability-dogfood/14-GATE-SMOKE-TEST.md` (2026).
- **Live session restart plus a real ship run**: reinstall, restart a real Claude Code session, let
  the hook fire naturally, and run `/gsd-ship` to observe the advisory gate line in a live transcript.
  Highest fidelity — it exercises the actual hook dispatcher and the actual `ship.md` step rather than
  the commands underneath them. `https://code.claude.com/docs/en/hooks` (2026) documents the
  SessionStart event this depends on. Rejected: a session restart cannot be driven or asserted from
  inside a plan run, which would make the criterion unverifiable by any automated check.
- **Direct capability grant, skipping the hook**: run
  `gsd-tools capability install <path> --scope global --yes` against the installed bundle. Fewest
  moving parts, and it is the same command the hook ultimately runs — visible in
  `plugins/beads-lifecycle/hooks/capability-auto-install.sh` (Phase 10.1 D-05, 2026). Rejected on
  validity, not size: it bypasses precisely the link ROADMAP success criterion 3 asks about, so a pass
  would prove the installer works while saying nothing about whether the extracted plugin
  auto-installs.

Decided by: simplicity/LOC. The three tie on runtime cost; the live-session option is eliminated
because it cannot be asserted automatically, and the direct-grant option is eliminated because it
does not test the claim. Driving the installed hook is both the shortest runnable path and the only
one of the three that actually exercises the criterion end to end.
