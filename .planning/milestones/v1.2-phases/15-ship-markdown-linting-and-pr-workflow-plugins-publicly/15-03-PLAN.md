## Alternatives Considered

- **`url` source object (`{"source": "url", "url": "https://github.com/owner/repo.git"}`)**: a full
  HTTPS clone URL, so git's normal HTTPS credential resolution applies. This project already carries
  the shape twice in the same file, and the reason it is mandatory rather than optional is recorded in
  this repo's own history: `git show -s f706179` (2026-08-17) documents that the shorthand form clones
  over SSH and fails for users with no SSH key.
  `https://code.claude.com/docs/en/plugin-marketplaces` (2026).
- **`github` source object (`{"source": "github", "repo": "owner/repo"}`)**: the shorthand form, two
  fields instead of two-with-a-longer-string, and what Phase 12 originally shipped. Same doc,
  `https://code.claude.com/docs/en/plugin-marketplaces` (2026). Rejected: it is the exact regression
  commit `f706179` (2026) fixed, and ROADMAP success criterion 2 forbids it by name.
- **`git-subdir` source object (repository plus a `path` within it)**: would let both capabilities keep
  living inside `gsd-beads` as bundle subdirectories with no separate repositories at all. Same doc,
  `https://code.claude.com/docs/en/plugin-marketplaces` (2026). Eliminated by locked decision D-00,
  which requires each plugin to have its own repository.

Decided by: ecosystem support. All three resolve over the same git fetch and are the same size, so
performance and simplicity both tie; what separates them is which one works on an unmodified consumer
machine — and only the `url` form does for an HTTPS-only user, which is the measured, previously
reported failure this project already fixed once.
