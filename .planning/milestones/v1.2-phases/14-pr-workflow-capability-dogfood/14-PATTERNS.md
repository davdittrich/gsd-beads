**Path confinement helpers — copy verbatim, do not modify** (`lint.py` lines 30-53):
```python
def find_project_root(start):
    current = start.resolve()
    for _ in range(10):
        if (current / ".planning").is_dir():
            return current
        if current.parent == current:
            break
        current = current.parent
    raise ValueError(f"could not locate a .planning/ ancestor above {start}")


def confined(root, *parts):
    """Join parts onto root and reject any resolved escape (T-13-02)."""
    candidate = root.joinpath(*parts).resolve()
    try:
        candidate.relative_to(root)
    except ValueError:
        raise ValueError(f"path escapes project root: {candidate} not under {root}")
    return candidate
```

reuse-verbatim target for `PR.md`'s output path (V12 File/Path handling row).

```python
def gh_available():
    if shutil.which("gh") is None:
        return False, "gh not found on PATH -- install: https://cli.github.com"
    auth = subprocess.run(["gh", "auth", "status"], capture_output=True, text=True, timeout=15)
    if auth.returncode != 0:
        return False, "gh not authenticated -- run: gh auth login"
    return True, None
```

**Pure reduction function pattern** (`lint.py` lines 70-90, `count_violations` — mirrors what
D-01's rollup precedence function should look like: no I/O beyond one subprocess call, one
`subprocess.run`, explicit returncode branching before JSON parse):
```python
def count_violations(config_path, targets, rumdl_argv):
    argv = rumdl_argv + ["check", "--config", str(config_path), "--output-format", "json"] + [str(t) for t in targets]
    result = subprocess.run(argv, capture_output=True, text=True, timeout=60)
    if result.returncode == 2:
        raise RuntimeError(f"rumdl config/runtime error: {result.stderr}")
    if result.returncode not in (0, 1):
        raise subprocess.CalledProcessError(result.returncode, argv, result.stdout, result.stderr)
    return len(json.loads(result.stdout))
```
Analogous target shape for the rollup:
```python
def rollup_pr_status(buckets):

        return "failing"
    if "pending" in buckets:
        return "pending"
    return "passing"  # only "pass"/"skipping" remain
```

**Report writer — full-overwrite discipline, copy shape verbatim** (`lint.py` lines 93-113,
`_write_report`):
```python
def _write_report(out_path, phase_dir, generated_at, config_path, generated_from, violation_count, unavailable_reason=None):
    lines = [
        "---",
        f"phase: {phase_dir.name}",
        f"violation_count: {violation_count}",
    ]
    if unavailable_reason is not None:
        lines.append(f"unavailable_reason: {unavailable_reason}")
    lines.append(f"config: {config_path}")
    lines.append(f'generated_from: "{generated_from}"')
    lines.append(f"generated_at: {generated_at}")
    lines.append("---\n")
    body = (
        f"# LINT-REPORT.md: {phase_dir.name}\n\n"
        "> Regenerated every step. Do not hand-edit.\n"
    )
    out_path.write_text("\n".join(lines) + "\n" + body, encoding="utf-8")
```
For `PR.md`, add the extra `pr_gate_ok` derived-boolean field per RESEARCH.md Pitfall 1

## Shared Patterns

### Path confinement (V12)
**Source:** `.gsd/capabilities/markdown-linting/scripts/lint.py` lines 30-53
(`find_project_root`, `confined`)
**Apply to:** `pr_status.py`'s `PR.md` output path and any `git`/`gh` invocation touching a
repo-relative path. Copy verbatim per-capability (do not import across `.gsd/capabilities/*`
boundaries — explicit rule stated in `lint.py`'s own docstring, line 36-38).

### Fail-open notice discipline (B6)
**Source:** `.gsd/capabilities/markdown-linting/scripts/lint.py` `NOTICE` constant (line 27) +
`verify_post`'s guard/print/write/return-0 control flow (lines 116-176); `sync.py`'s `NOTICE`
constant (line 23) + `migrate_todos`'s print-and-return-0 shape (lines 288-299)
**Apply to:** All four `pr_status.py` fail-open branches — `gh` absent, `gh` unauthenticated
(PRW-04, two distinct notices per D-04), tool-crash-during-checks-call, and (separately, not a
notice) the PRW-03 no-open-PR case. Exactly one `print()` per failure case, always `return 0`
(never raise), always still write/overwrite the artifact with an explicit sentinel value.

### Gate predicate on a derived scalar, never the raw multi-state field
**Source:** `.gsd/capabilities/markdown-linting/capability.json` gate block (`equals: 0` on
`violation_count`, an already-scalar int) contrasted with RESEARCH.md's own Pitfall 1 analysis
of why `pr_status` (four-state) cannot be gated directly
**Apply to:** `PR.md`'s frontmatter must carry both `pr_status` (display) and `pr_gate_ok`
(boolean, gate target) — the one structural field this phase adds beyond either analog's shape.

### Declarative capability.json step/gate shape
**Source:** `.gsd/capabilities/markdown-linting/capability.json` (full file, 67 lines) and
`.gsd/capabilities/beads/capability.json` (full file, 186 lines, for the multi-step-point and
multi-gate-per-point shapes)
**Apply to:** `pr-workflow/capability.json` in full — `config.<id>.*` namespacing,
`when`/`onError: skip` on every step and gate, `blocking: false` for this phase's single
advisory gate (contrast with `beads`'s two `blocking: true` gates — PRW-02 is explicitly
advisory per requirement, do not copy `beads`'s blocking value).
