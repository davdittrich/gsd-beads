<objective>
One-shot migration of existing `.planning/todos/pending/` entries into bd issues (B12): a parseable
todo becomes a bd issue with mapped priority (severity), an `area-<area>` label, and a folded
Problem/Solution/Files description, then its file is deleted; an unparseable todo is left untouched
and reported separately from a bd-create failure. Delivered as a new `sync.py migrate-todos`
subcommand and a new `/gsd-migrate-todos`-style skill (D-12).

Purpose: closes the gap between hand-authored todos and bd as the single task-state substrate,
matching this project's core value that zero duplicated task-state bookkeeping survives in
`.planning/`.
Output: `migrate_todos()` + supporting parse/format helpers in `sync.py`, a new
`beads-migrate-todos` skill, two new test fixtures, and a `TestMigrateTodos`/`TestMigrateTodosReport`
test suite.
</objective>
