## Alternatives Considered

- **Inline in-repo anchors for the quiet-output definition**: define `quiet` once and illustrate it with two precedents the consuming agents already meet in this codebase — the gate script's `<plan_path>: <reason>` plus single `remediation: ...` stderr contract at `` `.gsd/capabilities/sota-numerics/scripts/check-alternatives.py:12-14` ``, and the `@file:<tmp>` stdout spill above `50000` bytes at `` `/home/dd/.claude/gsd-core/bin/lib/io.cjs:189-196` `` (both read directly and verified 2026-09-06). An anchor the reader has already seen costs fewer definition tokens to land than an anchor introduced from outside.
- **External CLI-convention pointer**: define `quiet` by citing the Command Line Interface Guidelines' Output and Errors sections instead — [clig.dev](https://clig.dev/) (read 2026-09-06). Rejected on token cost against the 45-line ceiling: CLIG explicitly argues *against* fully silent success for interactive human use ("it's rare that printing nothing at all is the best default"), so importing it would require an extra qualifying clause disowning that caveat for the agent-invoked scope D-12 sets, and the fragment would grow to say the same thing.
- **Shared "extended definition" fragment injected at all four contribution points**: one file, four `contributions[]` entries. Rejected and already rejected by the user in D-06. gsd-core injects `fragment.inline` verbatim at each point with no dedup or caching across points, so every render pays the full cost of the other three roles' slices — a 4x per-invocation multiplier ([Anthropic, "Effective context engineering for AI agents", 2025](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents); measured degradation with input length in [Chroma Research, "Context Rot", 2025](https://www.morphllm.com/context-rot)).

Decided by: performance. The deciding quantity is per-invocation prompt tokens on the consuming agent's context, which is a performance property of the rendered prompt and the highest-ranked criterion. Verified 2026-09-06 against `/home/dd/.claude/gsd-core/bin/lib/capability-validator.cjs:2672-2724`: gsd-core enforces only an 8 MiB DoS backstop on fragment size and applies no token-budget trimming to the contribution render path, so nothing below the author's own ceiling limits this cost.

### Internal design alternatives

- **Tracer on `quiet` versus tracer on `legible`**: `quiet` wins as the tracer dimension because it has two verified in-repo precedents to anchor against (D-13), so a failure in Task 1 is a failure of the architecture rather than of the wording. `legible` has no in-repo precedent and would confound the two.
- **Per-file line ceilings versus a single 45-line total**: per-file ceilings (planner 12, executor 15, verifier 9, ship 7 — summing to 43) give each task a bound it can check alone, rather than making every task's budget depend on tasks in other plans. The 45-line total from D-08 remains the hard gate; the per-file numbers are the checkable decomposition.
