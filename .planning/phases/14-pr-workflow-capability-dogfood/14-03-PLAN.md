## Alternatives Considered

### Mechanism: how the `gh`-absent state is produced for the live degrade cycle

- **Per-invocation `PATH` override to a scratch directory (selected)** — the technique already used
  and recorded in `.planning/phases/13-markdown-linting-capability-dogfood/13-GATE-SMOKE-TEST.md`
  (Step 4, this repo, 2026-08-18). Scoped to one process, reversible by ending that process, and
  leaves the machine's `gh` installation untouched.
- **Uninstalling or renaming the `gh` binary** — `https://cli.github.com/manual/` (v2.97.0,
  2026-07-31) documents installation but offers no scoped disable. Mutates machine state outside the
  repository and leaves the environment broken if the run aborts partway.
- **A container or throwaway VM without `gh`** — e.g. `https://docs.docker.com/reference/cli/docker/container/run/` (Docker CLI reference, actively maintained through 2025). Cleanest isolation, but the
  gsd-core runtime, its installed `ship.md` patch, and the `gh` auth session would all have to be
  reproduced inside it before the cycle could run at all.

**Decided by:** simplicity/LOC — the `PATH` override is one environment prefix on one command and is
already precedent in this repo; both alternatives cost setup work an order of magnitude larger for
the same observation.
