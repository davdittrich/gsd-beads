## Decisions Made
- Manually invoked `hooks/capability-auto-install.sh beads` mid-plan (before Task 1's tracer verify could pass) because the plan's tracer probe runs `gsd-tools capability state` from a throwaway scratch directory, which resolves the beads capability from the global-scope installed copy at `~/.gsd/capabilities/beads/` (materialized by Phase 10.1's auto-install mechanism), not from this repo's source bundle live. That global copy was still at version 0.1.0/default-false, stale from before this plan's edits, so the tracer's steps 3-4 initially failed with 0/7 configured instead of 7/7. Running the vendored auto-install hook re-hashed the bundle and re-ran `capability install --scope global --yes`, refreshing the global copy to match the source edit. This is the project's own documented detect-and-re-grant mechanism (see PROJECT.md Key Decisions, Phase 10.1 row) — normally fires automatically at every Claude Code SessionStart; running it manually mid-session was necessary because no new session started between the edit and the verify.

- **Verification:** Confirmed both preconditions independently: (1) `git show 252984f:.../beads-recall/SKILL.md | grep -c 'GSD > BEADS RECALL'` returns 2, proving the duplication existed before Task 2 ran; (2) the corrected `-ge 1` check, run alongside every other unmodified assertion in the Task 2 verify block, passes for all four files.
