**`gsd_tools()` resolver — source this verbatim, do not re-derive** (`ponytail-everywhere/hooks/gsd-tools.sh` lines 1-18):
```bash
gsd_tools() {
  if [ -z "${_GSD_TOOLS_ARGS_SET+x}" ]; then
    _GSD_TOOLS_ARGS_SET=1
    local _root
    _root="$(git rev-parse --show-toplevel 2>/dev/null)"
    if [ -n "$_root" ] && [ -f "$_root/gsd-core/bin/gsd-tools.cjs" ]; then
      _GSD_TOOLS_ARGS=(node "$_root/gsd-core/bin/gsd-tools.cjs")
    elif command -v gsd-tools >/dev/null 2>&1; then
      _GSD_TOOLS_ARGS=(gsd-tools)
    elif [ -f "${CLAUDE_CONFIG_DIR:-$HOME/.claude}/gsd-core/bin/gsd-tools.cjs" ]; then
      _GSD_TOOLS_ARGS=(node "${CLAUDE_CONFIG_DIR:-$HOME/.claude}/gsd-core/bin/gsd-tools.cjs")
    else
      _GSD_TOOLS_ARGS=()
    fi
  fi
  [ "${#_GSD_TOOLS_ARGS[@]}" -gt 0 ] || return 127
  "${_GSD_TOOLS_ARGS[@]}" "$@"
}
```
This file exists only under `ponytail-everywhere/hooks/`, not at repo root today — the root plugin's `capability-auto-install.sh` needs either its own copy of this exact resolver or (lazier, matches D-05's "vendored copies" framing) both `capability-auto-install.sh` files carry the resolver inline so the script has zero cross-file dependency within its own plugin.

**Fail-soft self-heal shape to mirror (not copy verbatim — different condition, same posture)** (`hooks/session-start.sh` lines 1-13, full file):

#!/usr/bin/env bash
# D-02/D-09: self-heal .beads/PRIME.md from the shipped source before bd prime reads it.
set -u

Pattern to copy: `set -u`, `PLUGIN_ROOT` derivation, a guarded conditional side-effect with `|| true` to stay fail-open, ending in the "real" invocation. The new script's D-04 divergence: unlike this file's silent `|| true`, the auto-install script must print a **visible** one-line warning on the `gsd_tools capability install` failure path specifically (not on every guarded branch) — do not blanket-silence like this analog does.

**`gsd_tools config-get` usage pattern for reading plugin config, if the sidecar design needs it** (`ponytail-everywhere/hooks/session-start.sh` lines 6-19, showing exit-code discipline: 127 = tool not found → soft default, nonzero-non-127 = real error → warn to stderr + default):
```bash
if [ -f "$PLUGIN_ROOT/hooks/gsd-tools.sh" ]; then
  . "$PLUGIN_ROOT/hooks/gsd-tools.sh"
  ENABLED="$(gsd_tools config-get ponytail.enabled --default true 2>/dev/null)"; ENABLED_STATUS=$?
  if [ "$ENABLED_STATUS" -eq 127 ]; then
    ENABLED=true
  elif [ "$ENABLED_STATUS" -ne 0 ]; then
    echo "ponytail: gsd_tools config-get ponytail.enabled failed (exit $ENABLED_STATUS); disabling advisory banner" >&2
    ENABLED=false
  fi
else
  ENABLED=true
fi
```
Reuse this exact `127 vs nonzero` branching discipline for the D-04 install-call: `127` (no `gsd-tools` resolvable at all) and a real nonzero exit from `capability install` should both hit the D-04 warn-and-fail-open path, but the warning text should say which case occurred (mirrors this analog's differentiated stderr messages).
