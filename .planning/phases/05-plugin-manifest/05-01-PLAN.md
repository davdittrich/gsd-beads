## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo → Claude Code plugin loader | `plugin.json` / `marketplace.json` are parsed by the loader; malformed or hostile paths cross here |
| repo → installer's machine | `/plugin install` copies the plugin directory into the installer's plugin cache; every tracked file in the source tree crosses this boundary |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-02 | Tampering | `marketplace.json.plugins[].source` | medium | mitigate | `source` is `./`, no `..` segment; Task 2's jq gate asserts `contains("..") == false`, matching the loader's own path-traversal rejection. |
| T-05-03 | Tampering | `claude plugin validate` assurance path | high | mitigate | Validation in marketplace-directory mode structurally never opens SKILL.md, so a single green run is indistinguishable from a check that never ran. D-09's double-run (Task 2) exercises both code paths; Task 1 additionally validates before `marketplace.json` exists. |
