### Filter-repo safety
- **D-03:** Take a full `git clone --mirror` backup to a local path before running `git filter-repo`. Insurance against the rewrite going wrong, even though the repo has no remote yet (`git remote -v` is empty — nothing pushed to lose either way, but local history is the only copy and filter-repo mutates it in place). — **Reversibility:** reversible if the mirror backup is taken first; **one-way** without it, since filter-repo rewrites commit hashes in place with no undo. Rationale for the rating: always take the mirror backup — do not skip this step.

### New GitHub repo creation
- **D-04:** Owner is `davdittrich` (confirmed via `gh auth status` — already authenticated, `repo` scope present). Repo name `gsd-beads`, public, `main` as default branch (existing local branch name, single branch, no other branches/tags besides `v1.0`).
- **D-05:** Do NOT auto-init with a placeholder README on `gh repo create`. Create the repo empty; push the existing (rewritten) history as-is. README.md is Phase 8 scope, written from verified commands — an auto-generated GitHub README would just need deleting/overwriting.
