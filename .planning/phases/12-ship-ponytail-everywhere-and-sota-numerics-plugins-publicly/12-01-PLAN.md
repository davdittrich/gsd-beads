## Alternatives Considered

- **`cp` to a scratch dir + fresh `git init` + `gh repo create --source=. --push`**: creates the
  standalone repo from current file state with no history machinery at all. `gh repo create --help`
  (gh 2.97.0, verified this session, 2026) documents `--source` as the existing-local-repo path, and
  `https://code.claude.com/docs/en/plugins-reference` (2026) confirms a plugin repo needs only
  `.claude-plugin/plugin.json` at its root.
- **`git subtree split -P ponytail-everywhere -b <branch>` then push that branch**: rewrites the
  subdirectory's commits into a synthetic branch whose root is the subdirectory, preserving Phase
  10/10.1/11 history. `git subtree --help` (git 2.55.0, verified this session, 2026).
- **`git filter-repo --subdirectory-filter ponytail-everywhere` against a mirror clone**: the
  highest-fidelity history extraction, and this repo's own precedent for filter-repo surgery lives in
  `.planning/phases/07-hygiene-publication/07-02-PLAN.md` (2026);
  `https://github.com/newren/git-filter-repo` (2026).
