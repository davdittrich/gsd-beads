inventing a fourth "shared runtime" plugin that every other plugin would then depend on — strictly

forced it.

predicate kind by what the check needs" — this phase is the first `command-exit-zero` user here.

Write `check-alternatives.py` as a stdlib-only Python 3 script and declare the gate that calls it,
then copy both to the repo-root dogfood location.

Script CLI: one positional argument `phase_dir`, parsed with `argparse`. Exit 0 = every plan
passes, exit 1 = one or more violations (each printed to stderr as `<plan_path>: <reason>`),
exit 2 = usage/IO error such as a non-existent or non-directory `phase_dir`. Do not print a JSON
`GATE_RESULT` — the generic `evaluateCommandExitZero` evaluator derives `block` purely from the
process exit code.

Path safety: resolve `phase_dir`, locate the project root by walking up to the nearest `.planning/`
ancestor exactly as `sync.py`'s `find_project_root` does, and reject a `phase_dir` that resolves
outside that root using `sync.py`'s `confined` idiom. Never pass any bytes read from a PLAN.md
body to a shell, `eval`, or `subprocess` — this script performs no subprocess calls at all.

Plan discovery: iterate `Path(phase_dir).iterdir()` and match filenames against an anchored regex
that accepts a dotted phase segment, not only two-digit ones — the pattern must match both
`11-01-PLAN.md` and `10.1-02-PLAN.md`. Beads' own `^(\d{2}-\d{2})-PLAN\.md$` is too narrow here;
widen the phase segment to `\d+(?:\.\d+)?`. Collect ALL matches and validate every one; never
return on the first match (RESEARCH Pattern 3). Zero matched plans is a pass, exit 0.

Per-plan validation, in order:
1. Locate the section heading with a MULTILINE, case-insensitive anchored regex for a line that is
   exactly `## Alternatives Considered` (allow trailing whitespace). Absent → violation
   `missing '## Alternatives Considered' section`.
2. The section body runs from just after that heading line to the next line starting with `## ` or
   to end of file.
3. Exemption (D-03): if the body's first non-blank content matches, case-insensitively, `N/A`
   followed by any run of non-newline characters containing `no mechanism choice` — accepting both
   the em dash and a plain hyphen as the separator — the plan passes with no further checks.
4. Alternatives: count body lines matching an anchored list-item-with-bold-name pattern
   (`-` or `*` bullet, then `**name**`). Fewer than 2 → violation
   `fewer than 2 named alternatives (found N)`. Each alternative's "entry text" is its bullet line
   plus all following more-indented continuation lines up to the next bullet at the same level.
5. Citation (D-06): each entry text must contain either an `http://`/`https://` URL or a
   backtick-quoted doc reference. Missing → violation naming the alternative.
6. Recency (D-07): each entry text must contain a 4-digit year matching `19xx` or `20xx`.
   Missing → violation naming the alternative.
7. Ranked criterion (D-09): the section body must contain at least one line matching, case
   insensitively, `Decided by:` followed by one of `performance`, `simplicity`, `LOC`,
   `ecosystem`, `maintenance` (allowing surrounding `**` bold markers and an optional leading
   bullet). Missing → violation `no 'Decided by:' line naming a ranked criterion`.
8. Mechanical plausibility (D-08's deterministic layer, RESEARCH Pattern 2(b)): reject an entry
   whose only citation URL has host `example.com`, `example.org`, `example.net`, or `localhost`,
   and reject an entry whose citation text is a bare `TODO` or `TBD` placeholder. Reject a year
   that is later than the current year or earlier than the current year minus 6, computed from
   `datetime.date.today().year` — never hardcode a year literal.

All regexes must be anchored where possible, use bounded character classes, and contain no nested
quantifiers (ReDoS mitigation, RESEARCH Security Domain). Bound the URL match length.
