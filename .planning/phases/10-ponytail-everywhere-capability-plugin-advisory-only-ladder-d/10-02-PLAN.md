## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| capability fragment → agent prompt | `fragments/*.md` content is injected verbatim into the `gsd-planner` subagent's prompt. This is an instruction surface: text placed here steers an agent's behavior. It crosses from repo-writable content into agent instructions. |
| `.planning/config.json` → capability activation | `ponytail.enabled` and `ponytail.level` are read from project-local config to decide activation and to populate `configValues`. Untrusted-writable input, but consumed only by gsd-core's own resolver, never by a shell. |
