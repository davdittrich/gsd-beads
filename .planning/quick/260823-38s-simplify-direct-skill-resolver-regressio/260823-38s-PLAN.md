# Quick task 260823-38s

**Mechanism:** Literal canonical fence equality plus one canonical dynamic run per distinct resolver or argv contract.

**Forbidden:** Markdown interpretation, placeholder transformation, repeated candidate matrices, production resolver changes, new dependencies, duplicate marketplace version fields, force pushes.

**Audit:** A JSON spy records selected `sync.py` path for resolver checks and exact `sys.argv[1:]` for unique command-shape checks; static counts audit copied internal source without execution.

## Objective

Simplify issue #4's direct-skill regression coverage, publish the patch-bumped
plugin, synchronize Claude Marketplace, and close the external ticket without
changing production behavior.

## Alternatives Considered

Ranks are ordinal; 1 is best. Decision order is performance, simplicity/LOC,
ecosystem support, then maintenance overhead.

- **Literal exact fence blocks plus canonical dynamic cases** — performance 1,
  simplicity/LOC 1, ecosystem 1, maintenance 1. Selected: no parser, no copied
  execution, and only Python's documented stdlib `unittest`, `tempfile`, and
  `subprocess` mechanisms ([Python 3.14 library documentation](https://docs.python.org/3/library/unittest.html),
  accessed 2026-08-23).
- **Keep generic Markdown parsing but deduplicate execution** — performance 2,
  simplicity/LOC 3, ecosystem 2, maintenance 3. Rejected because it preserves
  failure-prone fence discovery and a project-specific placeholder grammar even
  though CommonMark fences are a presentation construct, not the behavior under
  test ([CommonMark 0.31.2 specification](https://spec.commonmark.org/0.31.2/),
  2024).
- **Extract a shared production resolver script and test it once** — performance
  1, simplicity/LOC 2, ecosystem 2, maintenance 2. Rejected because it changes
  production packaging and four command surfaces outside the issue scope; the
  current bounded Bash candidate scan already uses native shell control flow
  ([GNU Bash manual](https://www.gnu.org/software/bash/manual/bash.html),
  accessed 2026-08-23).
- **Add a Markdown parser or snapshot dependency** — performance 3,
  simplicity/LOC 4, ecosystem 3, maintenance 4. Rejected because dependency and
  update cost exceed a literal source contract; CommonMark's current grammar is
  much broader than the exact ten blocks being protected
  ([CommonMark 0.31.2 specification](https://spec.commonmark.org/0.31.2/), 2024).

**Decided by:** performance first, then simplicity/LOC. The selected mechanism
runs only distinct behavior and deletes parser/placeholder machinery while the
single canonical resolver constant limits maintenance drift.

## Unchanged Components and Regressions Prevented

- All four direct skill files and their command semantics remain byte-identical.
- `hooks/lifecycle-dispatch.sh`, `scripts/sync.py`, `capability.json`,
  `.claude-plugin/marketplace.json`, gsd-core, auto-install code, and dependency
  state remain unchanged.
- Exact counts reject missing, duplicated, reordered, or rewritten fences.
- Concrete subprocess cases reject precedence drift, directory acceptance,
  unstable diagnostics, space-unsafe paths, duplicate argv coverage, and a
  lost optional `status` arity.
